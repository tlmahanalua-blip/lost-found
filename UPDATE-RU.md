# Обновить сайт на ноутбуке

Версия 3.2 добавляет кнопку **Delete report** в карточку вещи и Manage reports. Автор может удалить своё объявление; администратор — любое. Перед удалением появится подтверждение. Удаляются объявление, его фото, заявки и жалобы в текущей базе. Другие записи и аккаунты сохраняются. Отмены удаления в интерфейсе нет.

## Для твоей существующей установки

1. Закрой окно PowerShell, в котором сейчас работает сайт.
2. Распакуй новый ZIP **в отдельную папку** через «Извлечь всё».
3. В распакованной папке aitu-lost-found дважды нажми **UPDATE-WINDOWS.cmd**. Если расширения скрыты, файл может называться UPDATE-WINDOWS.
4. Дождись сообщения о запуске. Открой http://localhost:8000 и нажми Ctrl+F5. Окно запуска оставь открытым.

Этот помощник предназначен для твоей ранее показанной папки:

```
C:\Users\Asus\Downloads\AITU-Lost-and-Found-Registration-SQLite\aitu-lost-found
```

Он обновляет файлы сайта и сохраняет папки data, node_modules и файл .env. Если старая папка находится в другом месте, помощник остановится с ошибкой; понадобится её точный путь. Запускай файл после полного извлечения ZIP, а не внутри архива.

Перед переносом старой локальной базы сервер создаст **data/lost-found.db.before-v3.backup.db**. Имя Alua, пароль и объявления сохраняются. Перенос проверен на тестовых копиях версий 2.0 и 2.1; импорт твоей загруженной учебной базы также проверен. При npm start её 102 объявления добавляются один раз, сохраняя существующие записи.

## Если обновляешь вручную

Останови сервер. Скопируй содержимое новой папки aitu-lost-found в старую папку проекта с заменой файлов, сохранив data, node_modules и .env. Зависимости не менялись. В старой папке выполни:

```powershell
npm.cmd start
```

## Что проверить

- Вход в прежний аккаунт и имя Alua.
- Report an item → Lost / Found, дата и время, фото и контакты.
- Поиск и фильтры All statuses / Lost / Found.
- Новое объявление в My reports после перезапуска сервера.

Твой исходный файл базы уже включён как database/assignment3-original.db. Его 102 объявления появятся с отметкой Sample — это учебные записи. Ручной импорт не нужен. Подробности — в **DATABASE-RU.md**.

## Vercel

Обновление на ноутбуке не обновляет Vercel. Для Vercel замени исходники в связанном репозитории и сохрани настройки подключения к удалённой базе. Перед миграцией удалённой версии 2 сделай резервную копию средствами провайдера; автоматическая файловая копия доступна только локально. Инструкция размещения — DEPLOYMENT.md.
