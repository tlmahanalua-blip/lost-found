# Обновление AITU Lost & Found

Добавлено:

- Новый логотип: сердечко внутри метки на карте. Пастельно-розовый фон, розовые карточки и тёмно-розовые кнопки.
- Три варианта времени: **Exact time** — точное время; **Time range** — промежуток «с … до …»; **I don’t remember** — не помню время.
- Интерактивная карта: **Choose on map** → нажмите на нужное место или переместите метку. Можно указать корпус, этаж или аудиторию.
- Выбранное место и время сохраняются в объявлении. Из объявления можно открыть точку в 2GIS или Google Maps.

## Обновить сайт по прежнему адресу

1. Распакуйте `AITU-Vercel-Upload.zip`.
2. Откройте на GitHub репозиторий, из которого развёрнут ваш сайт `lost-found-two-brown.vercel.app`.
3. В корне репозитория нажмите **Add file → Upload files**.
4. Перетащите **всё содержимое папки `Vercel-upload`**: папки `public`, `api`, `lib` и остальные файлы. Не загружайте сам ZIP или внешнюю папку `Vercel-upload`.
5. Нажмите **Commit changes**. Если GitHub предлагает выбрать ветку, используйте ветку, подключённую к Vercel.
6. Дождитесь статуса **Ready** в Vercel и обновите страницу сайта с помощью **Ctrl + F5**.

Используется существующая база Turso. Дополнительные поля добавляются автоматически при первом обращении к API. Ранее созданные аккаунты и объявления сохраняются. Параметры подключения Vercel менять не требуется.

## Как пользоваться

**Report an item → Time found / Time lost:**

- **Exact time:** введите время.
- **Time range:** введите **From** и **To** на выбранную дату. Конец должен быть позже начала.
- **I don’t remember:** вводить время не требуется. В объявлении будет написано **Time not remembered**.

**Where did you find it? / Where did you last see it?**

Выберите область кампуса. В **Building, floor or room** можно уточнить корпус и аудиторию. Нажмите **Choose on map**, затем поставьте метку нажатием на карту. Метку можно перетаскивать. **Remove pin** убирает её. Карта необязательна.

В открытом объявлении отображаются сохранённые время, уточнение места и карта с меткой, если она была указана.

## Локальный запуск

В PowerShell откройте папку `Vercel-upload`, затем выполните:

```powershell
npm ci
npm start
```

Откройте `http://localhost:8000`. Для обновления уже существующего локального проекта можно использовать `UPDATE-WINDOWS.cmd` из распакованной папки; сначала закройте окно работающего локального сервера.

## Проверка

```powershell
npm run build
npm test
```

Проверены точное и неизвестное время, интервалы, сохранение координат, проверка неверных данных и обновление старой схемы без потери записей. Повторный запуск обновления сохраняет уже записанные интервалы и метки.

Карта использует Leaflet 1.9.4 и данные OpenStreetMap с фоном OpenStreetMap France / HOT. Фон загружается при открытии карты. Атрибуция сохранена. При недоступности фона остаются ввод координат и ссылки на внешние карты. Лицензия Leaflet: `public/vendor/leaflet/LICENSE`.
